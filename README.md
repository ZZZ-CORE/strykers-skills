# strykers-skills

Archive of skills and instructions built for the Empire Strykers team (also referred to as "Seth's team" in the archived files).

These files are kept as a backup. They are not maintained or in active use.

## Contents

### `strykers-creative-studio-gpt/` — Strykers Creative Studio (retired ChatGPT custom GPT)

Backup of the instructions and skills that powered the Strykers Creative Studio custom GPT, saved before the GPT was removed. Files are stored exactly as exported, with no edits.

- `GPT-INSTRUCTIONS.md` — the GPT's instructions.
- `skills/strykers-video-promo/SKILL.md` — the one implemented skill (vertical video promos from source footage).
- `docs/WORKFLOW.md` — intake, QA, and handoff checklist.
- `docs/24-SKILL-LIBRARY.md` — proposed 24-skill plan. These were specifications only; apart from `strykers-video-promo`, none were implemented.
- `references/stryker_agent_skill.md` — pasted Canva/Higgsfield tool reference used by the GPT.
- `README.md`, `CLAUDE.md`, `docs/CLAUDE-CODE-HANDOFF.md` — the project's original setup notes. Their repository names, GitHub setup steps, and "source of truth" wording describe the GPT project as it was, not this archive.

Note for reuse: some archived copy is event-specific (for example "USA VS MÉXICO" rivalry lines) and should be re-verified before reuse.
