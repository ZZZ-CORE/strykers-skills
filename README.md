# Empire Strykers Creative Studio

Welcome, Strykers team! This repository helps our creative tools make on-brand graphics, videos, captions, and campaign materials.

## What’s here

- `GPT-INSTRUCTIONS.md` — instructions for the Strykers Creative Studio GPT
- `skills/` — reusable creative-production skills
- `docs/24-SKILL-LIBRARY.md` — roadmap for the full skill library
- `CLAUDE.md` — instructions for Claude Code
- `docs/CLAUDE-CODE-HANDOFF.md` — quick handoff guide for Claude Code
- `references/` — supporting tool and workflow references

## Brand first

Use approved Strykers logos, colors, fonts, player images, sponsors, and event information. When something is not verified, mark it `NEEDS APPROVAL` rather than guessing.
